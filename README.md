# 第二届观猹大会 2026 · 参展项目全览

2026 年 10 月 23—25 日，第二届观猹大会在杭州龙坞茶镇举办。这个仓库把公开渠道能查到的参展项目、金猹奖名单和现场报道整理成一页网页，按五个展厅分类，方便逛展时扫读，也方便事后查某个产品。

- 大会主题：见证创造发生
- 场馆：杭州茶叶博览会会议会展中心三号展馆「百展堂」
- 官方并没有 A—E 字母展厅；A—E 是本页为了方便阅读做的映射，页内有一节专门说明

## 页面内容

| 区块 | 内容 |
|---|---|
| 概览 | 时间、地点、规模、主办方、六大体验板块 |
| 展厅地图 | A—E 厅与官方展区的对应关系；全文搜索框 |
| A 厅 | 百展堂核心产品区，36 条 |
| B 厅 | 猹工坊 AI 互动区，G01—G18，含找路指南 |
| C 厅 | 灵感制作所内容创作区，11 条 |
| D 厅 | 生态伙伴、AI 硬件与机器人、六项战略签约 |
| E 厅 | 红黑榜、观猹学社、商店、茶饮实验站、猹话会分论坛 |
| 舞台 | AI 艺人首演与 AI 音乐现场 |
| 金猹奖 | 首届获奖名单，未公开的奖项照实留空 |
| 来源 | 权威媒体、官方渠道、参会者分享与信息等级 |

## 怎么改

页面是纯静态的，没有构建步骤：

- 改内容：直接编辑 `index.html`，项目卡片是 `<article class="proj">`，复制一段改文字即可
- 改样式：`styles.css`
- 搜索、导航高亮、阅读进度：`app.js`
- 原始调研稿：`sources/` 下两份 Markdown，改动内容时以它们为底稿

本地预览：用浏览器直接打开 `index.html`，或在仓库目录跑 `python -m http.server 8080` 后访问 `http://localhost:8080`。

## 数据说明

- 调研日期：2026-10-27
- 官方未公开完整 100+ 参展商名单，本页只覆盖公开渠道（官网、权威媒体、参会者分享）能确认的项目
- 部分金猹奖奖项、多数展位号未披露，页内标为「待补充」
- 信息有错或想补项目，欢迎提 Issue

## 技术栈与依赖

| 层 | 用什么 | 为什么 |
|---|---|---|
| 页面 | 原生 HTML | 内容为主，不需要框架；任何静态托管都能跑 |
| 样式 | 原生 CSS | 用系统宋体/黑体，不引外部字体，国内访问和离线都不掉字 |
| 交互 | 原生 JavaScript | 只做搜索、导航高亮、阅读进度三件事，几十行足够 |
| 托管 | GitHub Pages | 静态站直接发布，无需服务器 |

没有 npm 依赖，也没有打包产物。
